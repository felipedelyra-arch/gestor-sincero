# Material de voz do Ferrér

Pasta para o material que mostra como o Sidney Ferrér fala e escreve. É a referência do terminal de Conteúdo para a página e para o Papo reto (`docs/persona-ferrer.md`).

O que colocar aqui:

- Textos dele: artigos, legendas, trechos dos livros, roteiros de aula ou de vídeo.
- Transcrições de falas: podcast Turno Sem Terno, palestras, áudios enviados.
- Frases que ele repete e expressões que ele evita.

Regras:

- Só material entregue ou autorizado por ele. Nada copiado de terceiros.
- O conteúdo desta pasta não é versionado (o repositório é público); só este README entra no git.
- Enquanto a pasta estiver vazia, a voz vem do `docs/BRIEFING.md` (§2 a §6).

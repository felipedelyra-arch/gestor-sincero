# Gestor Sincero

Landing page oficial do Gestor Sincero (Sidney Ferrér, S4 Marketing Digital, Academia de Gestores).

Next.js (App Router), TypeScript, Tailwind e Supabase.

```bash
cp .env.example .env.local
npm install
npm run dev
```

Verificação: `npm run typecheck && npm run lint && npm test`.

Documentação em `docs/` (plano, design, texto e perguntas em aberto).
